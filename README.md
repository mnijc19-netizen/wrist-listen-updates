# 腕听

面向安卓手表的播客、网络电台与有声书客户端，最低 Android 5.0。

## 安装和更新

[直接下载 0.4.4 APK](https://raw.githubusercontent.com/mnijc19-netizen/wrist-listen-updates/main/apks/WristListen-0.4.4-M60T.apk)，或从 Releases 下载最新版 APK，直接覆盖安装；不要先卸载。应用内“设置 → 检查更新”可以获取后续版本，最后需要系统确认安装。

0.4.4 修复安卓 9 检查工具的读取超时兼容，并提供独立的网络 ADB 开启命令。只有核对服务端身份且命令 UID 为 0 时才尝试设置临时端口；后续电脑连接仍需验证。下载优先走与版本信息同域的 Raw 通道，APK 保留同一签名与 SHA-256 校验。

0.4.3 新增安卓 9 的高级工程服务身份检查：在诊断页复制命令，由用户到工程模式主动执行。工具尝试临时启动服务、核对服务身份，仅发送固定的 `id`，随后尝试还原启动开关并报告结果。不会自动开启网络调试，真实服务权限仍需实机验证。

0.4.2 在“设置 → 本机调试诊断”显示实际 Android/API、固件、开发者和 USB 调试状态，并检查可打开的系统入口。结果仅在手表本机显示，可复制；该功能不会上传诊断信息或自动修改系统开关。

0.4.1 修复安卓 5 / 6 的安装入口，改用系统安装会话并保留用户确认。若 0.4.0 或更早版本在旧安卓上提示无法打开安装入口，请先用浏览器下载 0.4.1 覆盖安装一次，后续使用软件内更新。

## 内容来源

Apple 播客、LibriVox、Internet Archive、BBC 和 NPR 公开节目，以及 Radio Browser 网络电台。支持公开 RSS 和喜马拉雅公开播客链接导入；BBC/NPR 为精选官方 RSS 导航。

## 验证范围

本版在 Android 6 和 Android 9 的 240 / 320 像素模拟器中测试。M60T 实机的息屏策略、音频硬件、蓝牙和系统安装限制仍需实机确认。目录及各节目音频需要相应网络可达。

本仓库仅发布安装包和版本信息，不上传收听数据、下载文件或签名私钥。
