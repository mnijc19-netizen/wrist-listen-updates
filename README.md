# 腕听 0.4.5

面向 M60T / XS watch 这类完整安卓手表的播客、网络电台与有声书客户端。中文界面、大按钮、深色背景，最低 Android 5.0（API 21），不依赖 Google 服务或 Wear OS。已经在安卓 6 / 9 模拟器运行验证；M60T 底层 Android 9 已由实机诊断确认；音频硬件、蓝牙、功耗与高级工程服务仍需实机验证。

## 下载和升级

- [下载 0.4.5 APK](https://raw.githubusercontent.com/mnijc19-netizen/wrist-listen-updates/main/apks/WristListen-0.4.5-M60T.apk)
- [公开更新仓库](https://github.com/mnijc19-netizen/wrist-listen-updates)
- 固定更新源：`https://raw.githubusercontent.com/mnijc19-netizen/wrist-listen-updates/main/latest.json`

0.1.0 没有更新入口，需要手动覆盖安装此次新版。0.2.0 及后续版本可从“设置 → 检查更新”升级。直接覆盖安装，不要先卸载，以保留订阅、收藏、进度及离线文件。

安卓 5 / 6 上若旧版提示“系统未开放此安装入口”，请先用浏览器下载 0.4.1 手动覆盖安装一次。0.4.1 改用系统安装会话处理旧安卓上的后续更新，仍需用户确认；安卓 7+ 保留原有受限内容 URI 安装流程。

首次应用内更新可能需要允许腕听安装应用，再返回确认系统安装。更新会检查 HTTPS、下载大小、SHA-256、包名、版本与当前签名；更新源不可访问会显示失败，不会报告“已是最新”。固件没有开放安装入口时，可改用手表浏览器下载后覆盖安装。

## 内容来源

| 来源 | 使用方式 |
| --- | --- |
| Apple 播客公共目录 | 搜索节目、主播，通过发布者公开 RSS 获取音频 |
| LibriVox | 浏览最新有声书，按作品名开头搜索，例如 `Alice` |
| Internet Archive | 按标题搜索公开音频合集，读取 MP3；同一文件有 64kbps 版本时优先选择小文件 |
| BBC | 精选官方 RSS：Global News Podcast、6 Minute English；搜索筛选这些节目名称 |
| NPR | 精选官方 RSS：News Now、Up First、Planet Money；搜索筛选这些节目名称 |
| Radio Browser | 搜索和收藏网络电台，优先提供 MP3 / AAC 等音频格式记录 |
| 手动导入 | RSS / Atom，以及喜马拉雅已公开 RSS 的专辑链接 |

喜马拉雅链接导入只读取已经公开 RSS 的播客，不是其全站搜索或会员内容接入。BBC/NPR 是精选节目导航，并非全站目录搜索。

## 使用

1. “播客 → 找节目”选择来源。进入节目后点“＋订阅”，或从首页“添加 RSS”粘贴地址。
2. 点击单集选择播放或下载。下载仅允许未计费 Wi-Fi；“离线”页自动更新可见下载的状态，也可手动刷新，长按单集删除/取消下载。只有系统下载成功且文件存在、非空才显示“已下载”；删除失败会保留记录以便重试。
3. 底部播放条打开播放器，点击播放器左上角“‹ 腕听”可返回列表继续收听。支持后台、息屏播放，断点续听、15/30 秒跳转、定时暂停、音量控制及安卓 6+ 播客倍速。直播电台不提供单集下载。
4. “设置”页可读取 Android 版本、API、型号、屏幕像素与密度，供下一轮 M60T 实机适配。
5. “设置 → 本机调试诊断”读取开发者模式、ADB、USB 状态、固件和允许当前应用打开的系统入口。信息仅在本机显示，可复制，不上传、不自动修改开关。发现入口只表示页面可启动，是否允许开启调试仍由系统页面控制。

安卓 9 诊断页可复制高级工程服务检查命令，粘贴到工程模式执行。工具尝试临时启动服务，仅发送固定的 `id` 检查身份，随后尝试还原开关并显示清理结果。普通应用不会自动执行此工具，不自动开启网络调试。实机成功与否以输出为准。

0.4.5 新增“复制 Root 权限诊断命令”，通过工程服务只读检查 SELinux、进程权限、ADB 端口与相关策略日志。网络开启命令明确区分端口写入失败与配置已报告，电脑实际连接仍需验证。更新后请重新复制命令。

网络连接和音频跳转解析在后台执行，支持取消；慢连接有一次自动重试。退到后台后停止界面轮询；界面内容未变时不反复更新文字。0.4.0 减少大 RSS 的临时内存复制，支持继承 `xml:base` 和嵌套 Media RSS 音频地址；更新下载使用独立临时文件，避免页面重建时互相干扰。

## 验证范围

详见 [验证记录](VALIDATION.md)。多轮检查覆盖安卓 6 / 9 的来源查询、离线音频、息屏续播、暂停/跳转/倍速、下载状态、后台轮询与 240/320 像素界面；安卓 9 完成 Wi-Fi 下载后断网播放及实际一分钟定时暂停。安卓 6 修复后的安装会话用本地未来版本测试包验证；安卓 9 使用公开更新源验证正式版升级。LibriVox 抽样音频本轮遇到上游 CDN 超时，未记作通过。

模拟器没有验证 M60T 的蓝牙耳机、扬声器、电池消耗、长时间后台保活及厂商安装策略。不同节目、地区网络和失效电台仍可能导致连接或格式错误。公开音频目录与内容会变化；不提供登录、会员内容解锁或跨设备同步。卸载会删除本地数据。

## 构建与发布

Windows、JDK 17、Android SDK Platform 35 / Build Tools 35；无第三方运行时依赖。

```powershell
.\build.ps1 -Jdk 'C:\path\to\jdk-17' -BuildTools 'C:\Android\Sdk\build-tools\35.0.0' -AndroidJar 'C:\Android\Sdk\platforms\android-35\android.jar'
```

APK 位于项目父目录 `outputs/wrist-listen`，临时文件和签名密钥位于 `work/wrist-listen-build`。后续版本必须保留同一 `.jks` 及口令文件，并增加 `AndroidManifest.xml` 的版本代码；target API 28 是旧系统侧载兼容策略，不满足当前 Play 商店新应用上架要求。

公开托管已经得到用户授权。准备 `outputs/wrist-listen/public-release` 的 APK、latest.json、README 和说明后，运行 `publish-updates.ps1` 或 `publish-updates.py`。它们通过已登录的 GitHub CLI 在内存取得认证，先核对本地包，再发布 APK，最后更新版本信息；不会上传源码、收听数据或签名私钥。已公开版本如果字节变化会拒绝覆盖，需增加版本。

发布器将同一签名 APK 存为 Release 资产和 apks 下的版本文件。新版本优先使用 Raw 同域地址，匿名下载校验通过后才更新 latest.json；已有版本的 APK 字节不同会拒绝覆盖。

核心/JVM 测试在 `tests`，原生安卓测试 APK 源码在 `tests/android`。测试 APK 只用于模拟器，不随用户安装包发布。旧系统 HTTPS 兼容仅补充官方 ISRG Root X1，保留证书链及域名校验；证书来源和指纹记于 `LegacyTls.java`。
